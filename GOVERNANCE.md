# Governance

Nucleus is maintained by the NucleusKit maintainers.

## Maintainer Responsibilities

Maintainers are responsible for:

- project scope and roadmap
- release decisions
- API and CLI compatibility policy
- security response
- reviewing pull requests
- enforcing contribution and conduct rules

## Decision Making

Nucleus uses maintainer consensus for major decisions. For routine changes, approval from one maintainer is enough unless the change affects public contracts, module layout, security-sensitive automation, or release policy.

Major changes should be proposed as issues, discussions, or ADRs before implementation.

## Project Boundary

Nucleus is an AI-first Go microservice kernel. The project does not aim to become a business framework bundle, a platform UI, a service mesh, or a private SDK compatibility layer.

Changes that expand the project boundary should include a clear motivation, alternatives considered, and compatibility impact.
